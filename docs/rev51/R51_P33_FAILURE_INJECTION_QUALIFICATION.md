# Runtime Rev5.1 P33 — Failure Injection Qualification Contract

P33 enumerates required compute, credential, agent, evidence, control-plane, and billing failure classes and evaluates normalized scenario results against no-blind-rerun, no-duplicate-billing, authoritative-state, credential-fence, authorization, and billable-residue invariants. Live failure injection remains a later qualification action; this slice defines and tests the evaluator.
