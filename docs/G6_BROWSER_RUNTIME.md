## Scope

G6 is limited to Chromium/Playwright execution of the target project's declared browser npm script. The Runtime does not accept arbitrary browser steps, commands, arguments, environment injection, or a custom browser DSL. Browser execution is bounded to five minutes. Automated browser success does not constitute visual certification.
